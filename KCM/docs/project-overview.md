# Campus Connect Project Overview

## Purpose
Campus Connect is a student-focused mobile application designed to help learners stay connected with campus life, announcements, events, and important information in one place.

## Target Users
- Current students
- New students onboarding to campus
- Student support and admin teams
- Clubs and organizations sharing updates

## Planned Features
- Welcome dashboard for students
- Campus announcements feed
- Event and activity highlights
- Navigation between core app sections
- Future integration with cloud data and authentication
- Offline-friendly local persistence and device-aware features

## Week 1 Foundation
This week establishes the project structure, Expo setup, and the initial welcome screen for Campus Connect. The app is built as a continuing long-term project that will be extended through the remaining weeks of the course.
